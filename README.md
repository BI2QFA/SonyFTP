# Sony FTP传输

## 介绍

适用于索尼相机，可以启动一个根目录位于SD卡根目录的FTP服务器，从而解决索尼老机型不能通过无线方式传输RAW格式照片的问题。

## 兼容性

仅在A6300上测试正常，理论上适用于所有可安装APK程序的索尼相机。

## 安装方法

使用[Sony-PMCA-RE](https://github.com/ma1co/Sony-PMCA-RE)将APK文件安装至兼容的索尼相机。
